The MORIE packages, signed for apt and dnf

One repository for the morie toolkit and command-line tool and the R packages rmorie, rmoriedata and rmoriebricklayer, on Debian, Ubuntu, Fedora and RHEL, for amd64 and arm64.

sudo apt install morie

Set up

Add the repository, then install

The repository and every package in it are signed. Add the key and the source once; after that, new versions arrive with your normal system updates.

01Add the repository

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://apt.rmorie.com/key.gpg \
  | sudo gpg --dearmor -o /etc/apt/keyrings/rootcoder007.gpg
echo "deb [signed-by=/etc/apt/keyrings/rootcoder007.gpg] https://apt.rmorie.com/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/morie.list
sudo apt update
sudo dnf config-manager addrepo \
  --from-repofile=https://apt.rmorie.com/rpm/morie.repo

Fedora 40 and older: sudo dnf config-manager --add-repo https://apt.rmorie.com/rpm/morie.repo

sudo dnf install epel-release              # the R packages need EPEL and CRB
sudo dnf config-manager --set-enabled crb
sudo dnf config-manager --add-repo \
  https://apt.rmorie.com/rpm/morie.repo

02Install what you need

sudo apt install morie

Packages

What’s in the repository

The R packages install the package of the same name from r-universe (its dependencies from CRAN) and compile it on your machine, so the first install takes a few minutes. Removing the package removes it from R again.

morie

The Python toolkit and the morie command, installed from PyPI into its own environment under /opt/morie.

Python 3 · amd64, arm64

rmoriebricklayer

Reproducible data capsules: provenance, signing and drift checks for the tables behind a result.

R 4.1+ · Debian 12+, Ubuntu 22.04+

rmoriedata

Access to the hosted tables, with privacy checks on what is released.

R 4.3+ · Debian 13+, Ubuntu 24.04+

rmorie

The R toolkit: the analyses and methods of the MORIE ecosystem.

R 4.3+ · Debian 13+, Ubuntu 24.04+

Fedora and EPEL 9/10 carry the R versions all four need.
