morie — signed apt / dnf repository

morie is a multi-domain scientific computing toolkit (Python + R), AGPL-3.0-or-later. This site serves its signed .deb and .rpm packages.

Debian / Ubuntu (apt)

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://rootcoder007.github.io/apt-morie/key.gpg | sudo gpg --dearmor -o /etc/apt/keyrings/rootcoder007.gpg
echo "deb [signed-by=/etc/apt/keyrings/rootcoder007.gpg] https://rootcoder007.github.io/apt-morie/apt stable main" | sudo tee /etc/apt/sources.list.d/morie.list
sudo apt update && sudo apt install morie

Fedora 41+ (dnf5)

sudo dnf config-manager addrepo --from-repofile=https://rootcoder007.github.io/apt-morie/rpm/morie.repo
sudo dnf install morie

Fedora ≤ 40 / RHEL (dnf4)

sudo dnf config-manager --add-repo https://rootcoder007.github.io/apt-morie/rpm/morie.repo
sudo dnf install morie

Contents

  • apt/ — Debian / Ubuntu pool + signed Release (amd64, arm64)
  • rpm/ — Fedora / RHEL packages + repodata (x86_64, aarch64)
